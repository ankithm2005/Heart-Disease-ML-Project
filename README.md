# Heart Disease Prediction - Machine Learning Project

## Project Overview

This project develops a machine learning classification system to predict the presence of heart disease using health-related features.

The project covers data inspection, preprocessing, feature scaling, model training, model comparison, and evaluation of the best-performing model.

## Objectives

- Inspect the Heart Disease dataset
- Identify and handle duplicate records
- Separate features and target variable
- Perform an 80/20 train-test split
- Scale the input features
- Train multiple machine learning classification models
- Compare model performance
- Select the best-performing model
- Evaluate the best model using a classification report and confusion matrix

## Dataset

**Dataset:** Heart Disease Dataset

**Source:** Kaggle

The dataset contains health-related features used to predict the presence or absence of heart disease.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Data Preprocessing

The following preprocessing steps were performed:

- Dataset inspection
- Missing-value checking
- Duplicate detection and removal
- Separation of input features and target variable
- Stratified 80/20 train-test split
- Standard feature scaling using StandardScaler

## Machine Learning Models

Three classification algorithms were implemented:

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Random Forest

## Evaluation Metrics

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score

A model comparison table was created to identify the best-performing algorithm.

## Best Model Evaluation

The best model was selected based on its F1-Score.

The selected model was further evaluated using:

- Classification Report
- Confusion Matrix

## Project Conclusion

The project demonstrates how machine learning can be used to predict heart disease from health-related features. Multiple classification algorithms were compared using standard evaluation metrics, and the best-performing model was selected for detailed evaluation.
